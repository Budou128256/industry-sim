Phase 7c — 範囲の移動・反転・上書き
編集
範囲選択・設計図
見本（動きの確認用）
画面
左クリック: 設置（ドラッグで通った道どおりに連続）
右クリック: 撤去
レバー: 何も選ばずにクリックで入り切り
R: 回転（カーソルの下 / 選択中の向き）
ホイール: 拡大縮小
Shift / スペース + ドラッグ、中ボタンドラッグ: 画面を動かす
矢印キー / WASD: 画面を動かす（Shift で速く）
F / Home: 全体を表示、+ / -: 拡大縮小
範囲を選ぶ → Ctrl+C / Ctrl+X / Delete、Ctrl+V で貼る
選んだ範囲の中をドラッグ / M: まとめて移動（中身ごと）
貼り付け・移動中: R 回す、V 上下反転（左右反転はボタン）、右クリック・Esc でやめる
重なる所は置きません。Ctrl（Mac は ⌘）を押しながら置くと上書き
下見の枠: 緑 置ける / 橙 上書き / 赤 置けない / 灰 同じ物がもうある
マウスを0.8秒止める: そのマスの詳細（種類・スタック）
Ctrl+Z: 元に戻す、Ctrl+Y: やり直す（置き方だけ。中身と時間は戻さない）
Esc: 選択を解除
何も選ばずにクリック: 中身を見る

■ ベルト上 / ■ 保管箱の中 / ● 床（赤枠）
ベルトの先が行き止まりだと床に落ちます。
アームは正面から取り、背面へ置きます。
スプリッターは横から入った物を、半分ずつ正面と背面（黒い点）へ送ります。
採掘機は正面（水色の点線）の鉱脈を掘り、背面（黄色の点線）へ出します。
炉は左下が入力、右下が出力、下の帯が進み具合です。
送り出し加工機は、できた製品を正面（黄色の点線）へ自分で出します。
発電機の電気は電線と機械をたどって24マス先まで届きます（薄い黄色）。
電線は発電機から遠いほど暗く、届いていないと灰色です。隣の機械にも線がつながって見えます。
電線は機械の下にも置けます。右クリックは機械を先に消します。
赤い × は電気が届いていない印です。
