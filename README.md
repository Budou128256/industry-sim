# 工業シミュレーション基盤

ブラウザで動く、汎用の工業シミュレーション基盤。
特定のゲームの複製ではなく、**データ（`data/` の JSON）を足すだけで中身が増える土台**を作ることが目的。

段階的に作っており、現在は **Phase 7c（範囲のまとめて移動・貼り付けの下見・上書き・反転）** まで。
進行状況と次にやることは [PLAN.md](PLAN.md)、設計の約束は [ARCHITECTURE.md](ARCHITECTURE.md) にあります。

## 動かす

Node.js は使いません。Python 3 があれば動きます。このフォルダ（`serve.py` のある所）で、使っている環境に合わせて次のどれかを実行します。

| 環境 | コマンド |
|---|---|
| GitHub Codespaces / Mac / Linux | `python3 serve.py` |
| Windows（Python ランチャーあり） | `py -3 serve.py` |
| Windows（ランチャーなし） | `python serve.py` |

「工業シミュレーション基盤  ->  http://127.0.0.1:8080/」と出たら、そのアドレスを開きます。
テストは末尾に `/tests.html`、速さの測定は `/bench.html` を付けます。止めるには Ctrl+C。

- Codespaces では、右下の「Open in Browser」か「ポート」タブの 8080 から開きます。
- 8080 が使われているときは、番号を付けると変えられます（例: `python3 serve.py 8000`）。

ES モジュール（`import` / `export`）は `file://` では読み込めないため、
標準ライブラリだけの小さな HTTP サーバ（`serve.py`）経由で開きます。

## 操作

| 操作 | 動き |
|---|---|
| 左クリック | 設置（押したままドラッグで、マウスの通った道どおりに連続設置。ベルトは進んだ向きになり、曲がり角もつながる） |
| 右クリック | 撤去 |
| R / 「回転 (R)」 | 回転（カーソルの下の建物 / 何も無ければ次に置く向き） |
| ホイール | 拡大縮小 |
| Shift / スペース + ドラッグ、中ボタンでドラッグ | 画面を動かす |
| 矢印キー / WASD | 画面を動かす（押している間。Shift で速く） |
| F / Home / 「全体を表示」 | 盤面全体が画面に収まるようにする |
| + / - | 拡大縮小（画面の真ん中を中心に） |
| 「範囲を選ぶ」→ ドラッグ | 範囲を選ぶ（水色の点線） |
| Ctrl+C / Ctrl+X / Delete | 選んだ範囲をコピー / 切り取り / 削除（ボタンでも可）。写すのは建物と向きだけで、中身は写さない |
| Ctrl+V / 「貼り付け」 | コピーした範囲をマウスに付けて、クリックで貼る（続けて何回でも）。マウスの位置に置いたときの姿を半透明で下見できる。右クリック・Esc でやめる |
| 選んだ範囲の中をドラッグ / M / 「移動」 | 選んだ範囲の建物をまとめて動かす（中身も一緒）。ドラッグは離したところ、M はクリックしたところに置く。置けない所が1つでもあれば動かさない |
| 貼り付け・移動中の R / V | R 時計回りに90度、V 上下反転（向きも鏡に映る）。左右反転は「左右反転」ボタンで（キーは無し） |
| 貼り付け・移動中の Ctrl+クリック | 重なる建物を撤去して上書きする（Mac は ⌘）。Ctrl なしでは上書きしない（重なる所は飛ばす・移動はしない）。下見の枠: 緑 置ける / 橙 上書き / 赤 置けない / 灰 同じ物がもうある |
| 「設計図として保存」 | 選んだ範囲に名前を付けて、このブラウザの中に保存する。一覧をクリックで貼り付け、⤓ でファイルに書き出し、× で削除。書き出したファイルは「読み込み」で一覧に戻せる |
| 左の「見本」 | 動きの確認用の盤面を開く（今の盤面と入れ替わる。確認してから開く）。▶ 再生で動く。中身は普通のセーブデータなので「読み込み」で examples/*.json を開いても同じ |
| マウスを0.8秒止める | そのマスの詳細を小さく出す（建物・ベルトの上・箱の中・炉の入出力・床の物を、何種類・何スタック・合計いくつと1スタックずつ。電気の強さ・鉱脈も） |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z）/ 「元に戻す」「やり直す」 | 置き方の操作を1回ずつ戻す・やり直す（設置・撤去・回転・移動・貼り付け・切り取り・削除・鉱脈・全消去・読み込み。100回まで）。中身と時間は戻さない（全消去・読み込みと、まとめて移動だけは中身ごと戻る） |
| Esc | 選択を解除 |
| 何も選ばずにクリック | そのマスの中身を見る（ベルト上・箱の中・床） |
| ▶ 再生 / 1 tick / 1 秒 | 時間を進める（1秒 = 20 tick） |
| 「アイテムを置く」 | クリックしたマスに選んだアイテムを10個置く（動作確認用） |
| 電力表示 | 電気が届いている範囲を黄色く塗る（押すたびに切り替え） |
| 全消去 | 盤面を空にする |
| 書き出し / 読み込み | 盤面を `.json` ファイルに書き出す / ファイルから読み込む（今の盤面と入れ替わる） |
| 自動保存 | 盤面が変わると、このブラウザの中に自動で保存し、次に開くと続きから始まる |
| 「鉱脈を置く」 | クリック・ドラッグで選んだ鉱石の鉱脈を置く。右クリックで消す |

## 構成

```
index.html        画面
serve.py          開発用サーバ（標準ライブラリのみ）
tests.html        テストの実行ページ
bench.html        速さの測定ページ（大きな盤面を敷き詰めて時間を測る）
data/             中身の定義（items / buildings / recipes）。index.json が目録
examples/         見本の盤面（動きの確認用。普通のセーブデータ）。index.json が目録
tools/            make_examples.mjs: 見本を作り直す（Node が要る。無くても examples/ はそのまま使える）
src/
  core/           盤面の論理。DOM も描画も知らない
    registry.js   data/ を読んで定義を保持する
    grid.js       座標・向き・大きさ・マスの鍵（数値）
    chunks.js     盤面を 32x32 の区画に分けて、マスごとの値を持つ
    world.js      建物の集合と占有マス（物の層・床の層・鉱脈。チャンクで持つ）。変更の記録。保存/復元
    placement.js  置ける/置けないの判定、設置・撤去・回転、ドラッグで通った道どおりに置く
    sim.js        時間を進める（1秒 = 20 tick）。中身（ベルト・箱・炉・採掘機・床）の持ち主。変わった所の近くだけ計算し直す
    belt.js       ベルトを線にまとめて運ぶ
    history.js    元に戻す / やり直す（置き方の変更を記録して逆に当てる）
    blueprint.js  設計図（範囲を写す・回す・反転・貼る・上書き・まとめて移動）
    splitter.js   スプリッター（横から入った物を半分ずつ正面と背面へ）
    inserter.js   アーム（正面から取り、背面へ置く）
    inventory.js  保管箱のスロットとスタックの列
    machine.js    加工機（炉・送り出し加工機）。レシピで原料を製品に変える
    miner.js      採掘機。正面の鉱脈を掘って背面へ出す
    snapshot.js   画面に映る範囲の写し（Worker から画面へ送る）
    save.js       セーブデータの形（作る・読む・読めないときの理由）
    power.js      電力。発電機から電線・機械をたどって届く範囲
  worker/
    worker.js     Web Worker の入口。ここで World と Sim を動かす
    engine.js     World と Sim を持ち、画面からの命令を実行して時間を進める
  client.js       画面から Engine を呼ぶ窓口（Worker が使えなければ同じスレッドで動かす）
  storage.js      ブラウザの中（IndexedDB）への保存
  render/         World（の写し）を読んで描くだけ
    renderer.js   Canvas に描く
    view.js       Worker から届いた写しを World / Sim と同じ形に戻す
  input/          入力をコマンドに変えるだけ（World は触らない）
  app.js          上記をつなぐ唯一の層
  tests.js        core の自動テスト
  bench.js        速さの測定
```

守っている約束（詳細は ARCHITECTURE.md）:

- `src/core/` は DOM も描画も知らない（そのため Web Worker の中で動かせている）
- 描画は World（の写し）を読むだけ、入力はコマンドを出すだけ
- ゲームの中身はコードに埋めず `data/` に置く
- どの段階でも動く状態を保つ
